# Amazon ML Challenge 2026: UI/UX Specification

**Document Path:** `docs/UI-UX.md`  
**Status:** NOT APPLICABLE  

---

### Statement of Non-Applicability

**UI/UX is not applicable to the current competition solution because the deliverable is a batch ML pipeline and submission package.**

### Rationale:
1. **Competition Deliverable:** The competition requires delivering:
   * Two tab-separated data files (`matching_results.tsv` and `candidate_pairs.tsv`)
   * A reproducible Python codebase under `code/business_entity_resolution/`
   * A technical methodology writeup (`Documentation_template.md`)
2. **Execution Environment:** The solution runs entirely headless in batch mode on local workstations and scoring servers without human-in-the-loop interaction.
3. **No End-User Application:** The project does not involve a consumer-facing web application, mobile app, or graphical dashboard. Building a graphical user interface is explicitly out of scope and would waste computational resources and engineering bandwidth.
